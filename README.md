# Примитивная База данных

Учебный проект №2 по курсу «Программирование на Python».
Малакаева Софья группа М26-555

Консольная база данных:
таблицы с типизированными столбцами, CRUD-операции, хранение в JSON-файлах.

Поддерживаемые типы данных: `int`, `str`, `bool`.

## Установка и запуск

```bash
uv sync
uv run database
```

То же самое через Makefile:

```bash
make install
make run
```

Установка пакета и запуск командой `database`:

```bash
uv build
uv tool install dist/primitive_db-0.1.0-py3-none-any.whl
database
```

## Структура проекта

```
src/primitive_db/
├── main.py        # точка входа, запускает run()
├── engine.py      # главный цикл и разбор команд
├── core.py        # логика таблиц и CRUD
├── parser.py      # разбор условий where / set и списка значений
├── decorators.py  # handle_db_errors, confirm_action, log_time, create_cacher
├── constants.py   # константы: имена файлов, допустимые типы
└── utils.py       # чтение и запись JSON-файлов
```

Где хранятся данные:

- `db_meta.json` — описание таблиц (имена и столбцы);
- `data/<таблица>.json` — записи каждой таблицы.

## Команды

| Команда                                                                    | Что делает                 |
| -------------------------------------------------------------------------- | -------------------------- |
| `create_table <таблица> <столбец:тип> ...`                                 | создать таблицу            |
| `drop_table <таблица>`                                                     | удалить таблицу            |
| `list_tables`                                                              | показать список таблиц     |
| `insert into <таблица> values (<значение>, ...)`                           | добавить запись            |
| `select from <таблица>`                                                    | показать все записи        |
| `select from <таблица> where <столбец> = <значение>`                       | показать записи по условию |
| `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` | обновить запись            |
| `delete from <таблица> where <столбец> = <значение>`                       | удалить запись             |
| `info <таблица>`                                                           | информация о таблице       |
| `help`                                                                     | справка                    |
| `exit`                                                                     | выход                      |

Правила ввода значений:

- строки всегда пишутся в двойных кавычках: `"Sergei"`;
- числа без кавычек: `28`;
- логические значения: `true` или `false`;
- столбец `ID` создаётся автоматически и в `insert` не указывается;
- все поля обязательны;
- запятая внутри строки в кавычках не поддерживается.

## Управление таблицами

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool

>>>Введите команду: create_table users name:str
Ошибка: Таблица "users" уже существует.

>>>Введите команду: list_tables
- users

>>>Введите команду: drop_table products
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Ошибка: Таблица "products" не существует.

>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

## CRUD-операции

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>>Введите команду: select from users where age = 28
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".

>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок, подтверждения, кэш

Эти возможности реализованы декораторами и замыканием из `decorators.py`.

**`handle_db_errors`.** Перехватывает `FileNotFoundError`, `KeyError`,
`ValueError` и любые другие исключения в функциях `core.py` и печатает
понятное сообщение вместо traceback. Ожидаемые ошибки (таблицы нет, неверное
число значений, неверный тип) по-прежнему проверяются через `if`, декоратор
служит страховкой от непредвиденных.

**`confirm_action(action_name)`.** Перед опасной операцией спрашивает
подтверждение. Применён к `drop_table` и `delete`. Любой ответ, кроме `y`,
отменяет операцию:

```
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: n
Операция отменена.
```

**`log_time`.** Замеряет время выполнения через `time.monotonic()` и печатает
его. Применён к `insert` и `select`:

```
Функция insert выполнилась за 0.001 секунд.
```

**`create_cacher()`.** Замыкание с кэшем в словаре. `select` с одинаковым
запросом берёт результат из кэша; после любого изменения данных
(`create_table`, `drop_table`, `insert`, `update`, `delete`) кэш очищается.
